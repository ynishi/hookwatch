Accepting or rejecting a proposal is the human's, or a role agent's that the human named in deciders.json (by the agent type Claude Code puts in the hook input, not anything the agent says). Labelling a verdict, putting a jigs file in effect and pruning the ledger are the human's only. The working agent's tool calls must not be able to do any of them, whatever the command line looks like. Reading the ledger stays open to agents.
